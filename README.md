# Сайт-калькулятор для грузоперевозок (Газель + грузчики)

Одностраничный сайт для частника с Авито. Клиент выбирает машину, адреса, часы и
грузчиков, сразу видит **предварительную** цену и отправляет готовую заявку
исполнителю в WhatsApp или Telegram. Бэкенда нет: сайт бесплатно размещается
на GitHub Pages.

## План работы

**Ниша:** грузоперевозки на Газели с грузчиками, Москва и Санкт-Петербург.
Почему именно она:
- частников на Авито тысячи, решение принимает сам владелец;
- клиенты постоянно спрашивают «сколько будет стоить?», а правила цены
  (час, минималка, подача, этажи, км за МКАД/КАД) уже расписаны в объявлениях;
- один шаблон подходит всем, под клиента меняются только цифры.

**Где искать:** Авито → Услуги → Грузоперевозки → Москва / Санкт-Петербург.
Подходят объявления, где:
- в описании расписан прайс («минимальный заказ 2+1», «грузчик 600 ₽/ч»,
  «за МКАД 45 ₽/км»);
- есть отзывы (бизнес живой) и нет своего сайта;
- у продавца несколько машин или объявлений.

Соберите 20–30 таких объявлений в таблицу: имя, ссылка, цены, телефон.

**Как продавать:**
1. Для 5–10 лучших кандидатов заполните `config.js` их данными (10–15 минут
   на человека) и сделайте скриншот.
2. Напишите в чат Авито, сначала без ссылки:
   > Здравствуйте! Сделал под вас страницу для приёма заказов, с вашими ценами
   > из объявления. Клиент сам считает стоимость и отправляет вам готовую заявку
   > в WhatsApp. Скинуть ссылку посмотреть?
3. Кто ответил, тому пришлите ссылку и спросите, что поменять. Правки
   «под себя» и приводят к оплате.
4. **Цена:** 5–7 тыс. ₽ разово (настройка: название, цены, фото, мессенджер).
   Подключение Google Таблицы для самостоятельной правки цен — +1–2 тыс. ₽.

## Как настроить под клиента

Всё меняется в одном файле — **`config.js`**:

| Что | Поле |
|-----|------|
| Название, слоган, имя, рейтинг с Авито | `name`, `tagline`, `ownerName`, `rating`, `reviewsCount`, `sinceYear` |
| Город | `city` + `ringRoad` (Москва/«МКАД» или Санкт-Петербург/«КАД») |
| Куда приходят заявки | `whatsapp` (цифры, с 7), `telegram` (username без @), `phone` |
| Машины, цены, «занята» | `vehicles` (`price` — ₽/ч, `available`, `photo` — ссылка на фото) |
| Правила расчёта | `minHours`, `supplyHours`, `moverPrice`, `floorPrice`, `outsideKmPrice` |
| Доп. услуги | `extras` |
| Цвет | `accentColor` |

Пустой `telegram` или `whatsapp` — кнопка не показывается.

### Как считается цена

- машина: `price × (часы + supplyHours)`;
- грузчики: `moverPrice × грузчики × часы`;
- этажи без лифта (если есть грузчики): `floorPrice × (этаж − 1)` на каждом адресе;
- за МКАД/КАД: `outsideKmPrice × км` (×2, если `outsideRoundTrip: true`);
- плюс выбранные доп. услуги.

На сайте сумма подписана как **предварительная**: точную цену подтверждает исполнитель.

## Владелец сам меняет цены (Google Таблица, необязательно)

1. Создайте Google Таблицу с двумя колонками — ключ и значение:

   | A | B |
   |---|---|
   | g3.price | 1300 |
   | g4.price | 1500 |
   | g6.available | нет |
   | moverPrice | 600 |
   | minHours | 2 |
   | pack.price | 1500 |

   Ключи машин и доп. услуг — их `id` из `config.js` + `.price` или `.available`
   («да»/«нет»). Числовые правила — по имени поля (`moverPrice`, `floorPrice`,
   `outsideKmPrice`, `minHours`, `supplyHours`).
2. Файл → Поделиться → **Опубликовать в интернете** → лист → формат **CSV** → Опубликовать.
3. Вставьте полученную ссылку в `sheetCsvUrl` в `config.js`.

Теперь владелец правит цены и «занята/свободна» прямо в таблице с телефона.
Google обновляет опубликованную версию с задержкой в несколько минут. Если
таблица недоступна, сайт берёт цены из `config.js`.

## Как выложить в интернет (бесплатно)

GitHub → репозиторий → **Settings → Pages** → Source: *Deploy from a branch* →
выберите ветку и папку `/ (root)` → Save. Через 1–2 минуты сайт откроется по
адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Под каждого клиента удобно держать отдельную копию (форк или отдельный
репозиторий), чтобы у каждого была своя ссылка.

## Файлы

- `index.html` — разметка страницы;
- `config.js` — **все настройки клиента**;
- `app.js` — расчёт, заявка, загрузка таблицы;
- `styles.css` — оформление (светлая и тёмная тема).
